# RECCVS Goal D · 一般性与稳定性

**状态：开放。** 在明确的约束初值空间和临界集合的相对拓扑下，研究相关现象的稳定性、一般性及局部余维。原证明索引未列出专属于 D 的编号证明稿。本仓以定义、依赖与验收条件为起点。

## 研究路线

1. 固定规范切片、带权范数、正则中心和渐近平坦条件。证明所用的约束切片具备所需的 Banach 流形结构。
2. 分别定义完整色散集合和黑洞集合，并验证候选确在两者的拓扑边界上。把沿一参数族的结果与全空间的拓扑结论分开陈述。
3. 若主张临界集合局部余维一，给出定义该集合的 \(C^1\) 函数并证明其微分非零。
4. 对稳定性和一般性写明环境空间，区分全空间与临界集合的相对拓扑，明确采用开稠密还是残余。
5. 若讨论可见奇点或延拓性质，分别登记因果结论、所需的未来零无穷远条件和延拓正则性。把相关存在结论列为依赖。
